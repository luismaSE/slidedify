# Slidedify

App Android para ordenar canciones de Spotify en varias playlists con gestos tipo Tinder:
una canción por pantalla, se reproduce sola, y cada gesto (swipe arriba/derecha/abajo,
doble tap, etc.) la manda a la playlist configurada.
